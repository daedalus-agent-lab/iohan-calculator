# Печенье к приходу гостей — iohan #29553

## Что изменено

- Экран объясняет покупку печенья для гостей: исходный запас — 12 печений.
- По умолчанию: 3 гостя, нужно по 6, следующая пачка — 4. Три добавленные пачки дают 24 печенья, по 8 каждому и остаток 0.
- Состояние хранит список `purchases` с размерами уже добавленных пачек. Сумма всегда вычисляется как `12 + sum(purchases)`.
- Смена гостей, требуемой порции и размера следующей пачки не стирает историю покупки. Размер пачки действует только для следующего добавления.
- Отмена сохраняет и восстанавливает список покупки вместе с другими значениями.
- Кнопка пачки не заменяется при перерисовке; обработчик `keepFocus` оставлен, поэтому Enter можно нажать дважды подряд.

## Проверка

```bash
python3 test_plates.py
```

Тест покрывает путь `3 × пачка 4 → 24 / 8 / 0`, сохранение списка после изменения гостей и порции, арифметический контроль с четырьмя гостями, а также повторный Enter на кнопке пачки.
